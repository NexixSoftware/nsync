# Security Policy

## Supported Versions

As NSync is in pre-alpha all users are effectively testers thus no security guarantees shall be made until v0.8.0. 

## Reporting a Vulnerability

All vulnerabilities should be reported either through GitHub's private vulnerability reporting or by emailing an explanation and demonstration of the vulnerability to `security@nexixsoftware.com`.

Updates on vulnerabilities will be agreed on a timeline with the reporter and will generally follow this flow:

- if a vulnerability is identified, updates will be short and purposefully vague.
- an update will be released once a patch has been deployed, this update will be longer and include any significant findings or CVE disclosures.

Communications with the reporting party will be more frequent to ensure transparency. 

## Encryption

As said in the README, all claims of encryption before v0.8 are **purely** science fiction. Any vulnerability reports (before v0.8.0) relating to encryption of any kind will be rejected with prejudice.
